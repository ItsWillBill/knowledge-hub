# Knowledge Hub - Plateforme RAG d'Entreprise

## 🏗 Architecture
- **Backend**: Spring Boot 3.5.8, Java 21 (Virtual Threads), Spring Security, JPA, Flyway.
- **Frontend**: Angular 18, Nginx.
- **Data/Messaging**: PostgreSQL, Kafka.
- **DevOps**: Docker, GitHub Actions.

## 🚀 Lancement Rapide
1. Assurez-vous d'avoir Docker installé.
2. Clonez le projet : `git clone https://github.com/ItsWillBill/knowledge-hub.git`
3. Lancez tout le stack :
   ```bash
   docker-compose up --build
